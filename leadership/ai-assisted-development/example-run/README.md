# Пример: новый шаг завершён, предыдущий остаётся на review

**Наблюдение из реального stage-проекта:** добавлен второй уровень браузерной игры. В плане шаги 1 и 3 завершены, шаг 2 ожидает независимой пользовательской оценки. RUN_STATE описывает завершение отдельного запуска, а не всего проекта.

Названия, ID и данные ниже заменены. Это реконструкция для чтения кода, не исходный экспорт корпоративного запуска и не результат запуска всего процесса разработки с ИИ из этого репозитория.

## Что подтверждено источниками

В изученных плане, chronology, STEP и RUN_STATE есть:

- отдельный scope нового уровня при сохранении review предыдущего шага;
- отчёт Chromium на desktop/mobile: движение, прохождение, бой, рестарт, регрессия и отсутствие ошибок браузера;
- разделение обычных UI-проверок и детерминированного прохождения с тестовым доступом к состоянию;
- отказ зачесть успешную удалённую проверку плана, потому что она вернула другой проект;
- техническое завершение шага; отдельное подтверждение приёмки человеком в этом срезе не найдено.
